# OpenMyau 汉化版 (OpenMyau Chinese Localization)

![Preview](/images/image2.png)

本项目是 [OpenMyau](https://github.com/60124808866/OpenMyau) 的**非官方汉化版本**，旨在为中文用户提供更友好的界面和操作体验。

我们基于 OpenMyau 的**最新源码**，在不修改任何原始功能逻辑的前提下，完成了对客户端内所有界面文本、提示信息及配置选项的**完整中文本地化翻译**。其余代码未作任何修改，以确保与原版的兼容性和稳定性。


## ✨ 主要变更

*   **功能汉化**：对客户端用户界面、提示信息、功能界面进行了中文翻译。
*   **代码纯净**：**仅添加了汉化内容，未对任何功能逻辑、性能或核心代码进行修改**，确保与原版OpenMyau行为完全一致。
*   **基础功能同步**：继承了原版的所有特性。
